# Roblox Audio Converter

Aplikasi single-file HTML untuk mengubah audio menjadi OGG Vorbis secara lokal di browser.

## Cara menjalankan

Buka index.html di browser modern. Pilih MP3, WAV, OGG, M4A, AAC, atau FLAC, pilih speed, lalu konversi. Audio tidak di-upload ke server.

Encoder OGG dimuat dari library JavaScript yang dipin ke commit tertentu melalui jsDelivr.
